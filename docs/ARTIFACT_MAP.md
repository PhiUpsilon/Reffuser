# Manuscript Artifact Map

This file maps the manuscript artifacts reproducible from this public package to their commands and output locations. It does not claim that third-party baseline results or every review-only diagnostic is regenerated by this repository.

| Manuscript artifact | Command | Output |
|---|---|---|
| Reffuser rows in the main nine-dataset forecasting table | `bash scripts/reproduce_main_table.sh` | `checkpoints/Reffuser/<Dataset>_100_<input>_<output>/.../test_metrics.json` |
| One Reffuser dataset/horizon setting | `python scripts/run_reffuser.py --dataset Weather --input-len 96 --output-len 336 --gpu 0` | Matching directory below `checkpoints/Reffuser/Weather_100_96_336/` |
| Evaluation of a saved checkpoint | `python experiments/evaluate.py --config baselines/Reffuser/Weather.py --checkpoint <checkpoint> --gpus 0 --device_type gpu --batch_size 64` | Evaluation log and metric output produced by the runner |
| Data preprocessing for a selected setting | `python scripts/data_preparation/Weather/generate_training_data.py --input_len 96 --output_len 336` | `datasets/Weather/data.dat`, `index_in_96_out_336.pkl`, and `desc.json` |
| Public-package verification | `bash scripts/smoke_test.sh` | Terminal confirmation for data utilities, model components, CLI, and dry-run wiring |

## Main-Table Grid

The complete Reffuser grid uses four horizons for each of nine datasets. The default command runs the full grid. A reduced verification command is:

```bash
DATASETS=Weather HORIZONS=96 GPU=0 \
  bash scripts/reproduce_main_table.sh
```

The reporting procedure is documented in [RESULTS.md](RESULTS.md). The normalized main-table protocol must not be mixed with the denormalized RL-baseline protocol.
